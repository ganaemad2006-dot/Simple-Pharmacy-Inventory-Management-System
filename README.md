# **Pharmacy Management System 💊**

**A robust and efficient Pharmacy Management System built with C++. This project demonstrates the application of advanced programming concepts to solve real-world inventory problems.**

---

### **🚀 Key Features**
* **Medicine Management:** Full **CRUD** operations (Add, Display, Search, Delete, Update Quantity, and Save).
* **Advanced Data Structures:** Implemented using **Linked Lists** for dynamic memory management.
* **Professional UI:** Utilizes `iomanip` (`setw`, `right`) for a clean, table-like console interface.
* **Data Persistence:** Includes **File Handling** to save and load medicine data from text files.
* **OOP Principles:** Developed using **Object-Oriented Programming** for modular code.
